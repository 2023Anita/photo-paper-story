# 纸上奇遇 · Photo Paper Story

一个将摄影元素延伸成纸面手绘故事的 Codex Skill，支持找灵感、口述想法和上传照片改造。

## 作品风格

写实摄影 + 米白纤维纸 + 细线小人物 + 一个跨越摄影与纸面的视觉巧思。比如树影变围巾、毛衣纱线变电车轨道、窗框变梯子。

当前规则根据 13 张用户提供的参考图提炼，原始提示词尚未提供。当前仓库不包含这些参考图片，不宣称逐字还原原始提示词或保证相同生成结果。

## 安装

将整个 `photo-paper-story` 文件夹复制到 Codex 的技能目录：通常为 `~/.codex/skills/`；若配置了 `CODEX_HOME`，则使用其下的 `skills/`。保留文件夹结构，随后在新聊天中调用。仓库的 README 不属于 Skill 运行时必读内容。

## 三种调用方式

### 没有想法

```text
$photo-paper-story 我没有任何想法，给我一些建议。
```

Skill 先给出具体场景与视觉巧思，选定后生成。也可以说“你帮我决定，直接生成”。

### 有想法或口述

```text
$photo-paper-story 我想要一棵雪地里的树，小人把树影当围巾，温暖又有点幽默，不要文字。
```

可使用聊天界面的语音转文字。直接音频输入取决于当前环境是否支持音频理解或转写。

### 上传图片改造

附上照片，再输入：

```text
$photo-paper-story 把这张照片改成纸上奇遇风格，保留人物的脸和衣服。
```

如果还附上风格参考图，请说明每张图片的用途。多张照片可分别生成，也可明确要求合成。

## 默认与可调整项

- 默认一张 3:4 竖版图，照片上部、纸面下部，保持大量留白。
- 支持修改比例、情绪、连接方式、文字及必须保留的主体特征。
- 后续可说“人物再小一点”“换一个更有趣的连接”“去掉文字”。
- 有可用图像工具时生成或编辑图片；没有时输出完整可复制提示词，并明确图片未生成。
- 不绑定图像供应商，不包含密钥，不自动发布或上传作品。
